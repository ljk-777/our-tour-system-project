# 第十五周项目周报

## 一、本周项目整体进展

本周（6月14日—6月20日）为课程设计**验收周**，主线是功能终态收尾、验收材料准备与现场预演。本周完成两件大事：一是把上周尚未在周报中体现、但已陆续落地的最后一批功能全部收口并入主分支——AlgoDemo 算法演示页重构（改用天坛公园真实路线数据作默认示例）、日记 AIGC 回忆视频（服务端 ffmpeg 真实合成 MP4）、3D 星球晨昏线着色与真实游记弹幕联动、室内导航跨楼层路径、日记无损压缩（Huffman/LZ77/BWT）；二是按学院要求逐栏撰写并定稿了**《数据结构课程设计自评表(2026)》**，对照评分原则把五大模块、核心算法、验收数据量逐项核对，确认全部达标后形成可一键提交的版本。至本周末，系统六条核心算法（Dijkstra、A*、MinHeap/TopK、KMP、Trie/倒排索引、压缩）均已在页面层可见、可现场演示。

## 二、本周各模块进展

### 1. 验收自评表撰写与核对（`自评表填写内容.txt`）
- 逐栏撰写自评表全部内容：创新需求、智能体开发环境、系统架构、AI 开发模式、实践反思五项基本要求
- 对照评分原则核对五大功能模块的"完成的功能 / 核心算法 / 特色加分项"，确认逐条满足
- 核验验收数据量：景区/校园/建筑物 300、服务设施 78（14 类）、路网边 225、用户 11，全部达标
- 输出精简版与详细版两套，最终采用精简版以贴合"不超过 200 字"的篇幅要求

### 2. AlgoDemo 算法演示页重构（`src/frontend/src/pages/AlgoDemo.jsx`）
- Dijkstra/A*/2-opt 三个演示统一改用天坛公园真实路线数据作默认示例，现场可直接出图
- 补充 TopK 堆与全排序耗时对比、KMP 检索示例与应用说明，便于答辩时讲清算法价值
- A* 演示输出 nodesExplored 探索节点数，与 Dijkstra 直观对比启发式搜索的剪枝效果

### 3. 日记 AIGC 回忆视频（`src/backend/src/services/memoryVideoService.js`）
- 服务端引入 ffmpeg-static + fluent-ffmpeg，从用户日记照片真实合成带 Ken Burns 运镜的 MP4
- 解决本地无 ffmpeg 二进制导致的合成报错，改用自带二进制方案彻底跑通
- 前端 Diary 页接入视频生成入口与播放器，回忆视频可下载、可播放

### 4. 3D 星球增强与弹幕联动（`src/frontend/src/components/Earth3D.jsx`、`GlobeOverlay.jsx`）
- Earth3D 新增昼夜晨昏线 GLSL 着色叠加，地球呈现真实日照分界
- 弹幕改用真实游记数据（标题/点赞），与当前聚焦城市联动，点击弹幕跳转游记详情

### 5. 室内导航与压缩收尾（`src/frontend/src/components/IndoorNavigationPanel.jsx`、`src/backend/src/algorithms/compression.js`）
- 教学实验综合楼 1-5 层室内路网跨楼层路径、三种偏好（最短/少爬楼梯/无障碍）终验
- 日记无损压缩三算法（Huffman、LZ77、BWT+MTF+Huffman）输出压缩率与耗时，可横向对比

## 四、当前存在的问题

1. **自评表与对抗测试的真实运行差距** — 自评表中将 adversarial/ 红队/模糊/混沌测试与 MCP 服务器列为完成项，目录与脚本均真实存在，但尚未接入 CI 持续运行，review-agent 的全自动对抗循环更多是流程设计，验收后若继续维护应补上真实跑通记录。

2. **答辩 PPT 让位给自评表** — 上周计划的答辩 PPT 与演示脚本本周改为以自评表形式准备，若验收除自评表外仍需现场 PPT 讲解，需临时补一份精简演示稿。

3. **AIGC 视频依赖服务端 ffmpeg** — 回忆视频合成依赖 ffmpeg-static，验收机若网络受限导致首次依赖未装好，存在合成失败风险，演示前需提前在验收环境预跑一次。

4. **室内导航数据仅覆盖单栋楼** — 室内导航目前仅有教学实验综合楼 1-5 层数据，演示时需明确说明这是手动标注的样例建模，而非全校园室内覆盖。
